# 刘钧旭 - 个人简历网站

一个现代化、响应式的个人简历网站，展示前端开发技能和项目经验。

## 项目特色

- **现代化设计**：采用渐变背景和卡片式布局
- **响应式设计**：完美适配桌面、平板和移动设备
- **交互式技能条**：动态显示技能水平，支持颜色分级
- **动画效果**：滚动动画、悬停效果和技能条填充动画
- **主题切换**：支持深色/浅色主题切换
- **打印友好**：优化的打印样式

## 技术栈

- **HTML5**：语义化标签，良好的可访问性

- **JavaScript (ES6+)**：模块化编程，DOM操作，事件处理
- **Font Awesome**：图标库
- **Google Fonts**：Inter字体

## 安装和使用

### 本地运行

1. **克隆项目**
   ```bash
   git clone https://github.com/peanut4556/resume-website.git
   cd resume-website
   ```

2. **直接打开**
   ```bash
   # 使用任何HTTP服务器
   python -m http.server 8000
   # 或
   npx serve .
   # 或直接双击 index.html
   ```

3. **访问网站**
   ```
   http://localhost:8000
   ```

### 自定义内容

1. **修改个人信息**
   - 编辑 `CV.html` 中的个人信息部分
   - 替换头像图片路径

2. **更新技能数据**
   - 修改技能条百分比
   - 调整技能分类和内容

3. **自定义样式**
   - 编辑 `styles.css` 中的CSS变量
   - 修改颜色主题和布局
